# 🖥️ Vennus Portfolio 

> Un portafolio interactivo que simula un sistema operativo retro, construido con React.

🔗 **Demo en vivo:** [vennusamery.github.io/Portafolio26](https://vennusamery.github.io/Portafolio26)

---

## ✨ Características

- 🪟 Ventanas arrastrables tipo OS de escritorio
- 🖱️ Iconos de escritorio interactivos
- 📊 Barra de tareas funcional
- 🌀 Pantalla de carga con animación de boot
- 📁 Modales tipo explorador de archivos por proyecto
- 🎬 Secuencias de boot animadas en cada preview
- 🗂️ Pestañas: Demo en vivo, Explorador de archivos, Info

---

## 🛠️ Stack tecnológico

| Categoría   | Tecnología                           |
|-------------|--------------------------------------|
| Framework   | React                                |
| Estilos     | CSS con variables (estética retro pastel/cream) |
| Fuentes     | VT323, Special Elite, Courier Prime  |
| Deploy      | GitHub Pages                         |
| Gestor      | pnpm                                 |

---

## 📂 Estructura de datos

Todo el contenido (proyectos, certificados, textos) vive centralizado en:

```
src/data/portfolioData.js
```

Editar ese archivo actualiza todo el sitio sin tocar componentes.

---

## ⚙️ Instalación local

```bash
pnpm install
pnpm start
```

## 📦 Build y deploy

```bash
pnpm run build
pnpm run deploy
```

El deploy automático corre vía GitHub Actions en cada push a `main`.
